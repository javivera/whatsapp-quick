# WhatsApp Quick scope

This repository is **WhatsApp Quick** (`/Applications/WhatsApp Quick.app`). When working here, interpret “the app” and WhatsApp UI issues as referring to WhatsApp Quick, **not** WhatsApp Keyboard Desktop or any other WhatsApp app. Do not modify or reinstall other WhatsApp apps unless a shared-bridge change actually requires it or Javier explicitly asks.

The Quick card should have a fully opaque background; keep the native window transparent only so the card can park below the viewport and slide in without an opaque rectangular window appearing.

After changing Quick, install and restart `/Applications/WhatsApp Quick.app` and verify the installed code is running, per the parent project instructions.
